Beispiel für die Nutzung der Übersetzungs-API

Diese Seite zeigt, wie Sie unsere Übersetzungs‑API für die Textübersetzung verwenden können. Dieses Echtzeit‑Übersetzungstool unterstützt die Baidu‑Übersetzungs‑API und die Youdao‑Übersetzungs‑API.

Hinweis: Bevor Sie die Übersetzungs‑API verwenden, holen Sie bitte den entsprechenden API‑Schlüssel ein.

Verwendung

1 API‑Modul importieren: 
import TranslateAPI from './api.js';
2 API‑Schlüssel konfigurieren: 
// Festlegen des zu verwendenden API‑Dienstes
TranslateAPI.setService('baidu'); // oder 'youdao'

// Baidu‑Übersetzungs‑API‑Schlüssel festlegen
TranslateAPI.setApiKey('baidu', 'YOUR_APP_ID', 'YOUR_SECRET_KEY');

// Youdao‑Übersetzungs‑API‑Schlüssel festlegen
TranslateAPI.setApiKey('youdao', 'YOUR_APP_ID', 'YOUR_SECRET_KEY');
3 Übersetzungsmethode aufrufen: 
// Übersetzungs‑API asynchron aufrufen
async function translateExample() {
    try {
        // Text übersetzen, von Deutsch nach Chinesisch
        const result = await TranslateAPI.translate('Hallo Welt', 'de', 'zh');
        console.log('Übersetzungsergebnis:', result);
    } catch (error) {
        console.error('Übersetzungsfehler:', error.message);
    }
}

Unterstützte Sprachcodes

Im Folgenden sind die gebräuchlichen Sprachcodes aufgeführt:

  • zh - Chinesisch
  • en - Englisch
  • ja - Japanisch
  • ko - Koreanisch
  • fr - Französisch
  • de - Deutsch
  • es - Spanisch
  • ru - Russisch
  • auto - Automatische Erkennung (nur für die Ausgangssprache)

Vollständiges Beispiel

import TranslateAPI from './api.js';

// Übersetzungs-API konfigurieren
TranslateAPI.setService('baidu');
TranslateAPI.setApiKey('baidu', 'YOUR_APP_ID', 'YOUR_SECRET_KEY');

// Übersetzungsfunktion erstellen
async function translateText() {
    const sourceText = document.getElementById('source').value;
    const sourceLang = document.getElementById('from-lang').value;
    const targetLang = document.getElementById('to-lang').value;
    const resultElement = document.getElementById('result');

    resultElement.textContent = 'Übersetze...';

    try {
        const translatedText = await TranslateAPI.translate(sourceText, sourceLang, targetLang);
        resultElement.textContent = translatedText;
    } catch (error) {
        resultElement.textContent = `Übersetzung fehlgeschlagen: ${error.message}`;
    }
}

// Ereignislistener für den Übersetzungsbutton hinzufügen
document.getElementById('translate-btn').addEventListener('click', translateText);
Hinweis: In der Praxis sollten Sie Ihren API-Schlüssel sicher aufbewahren und nicht im Client-Code im Klartext speichern. In einer Produktionsumgebung sollte die API über den Server aufgerufen werden.

Fehlerbehandlung

Die Übersetzungs-API kann folgende Fehler zurückgeben:

  • API-Schlüssel nicht konfiguriert oder ungültig
  • Netzwerkverbindungsproblem
  • API-Aufruf überschreitet das Limit
  • Nicht unterstützte Sprachkombination

Bitte fügen Sie unbedingt geeignete Fehlerbehandlungslogik in den Code ein.
