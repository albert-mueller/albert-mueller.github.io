Nutzungshilfe

So verwenden Sie das intelligente Übersetzungssystem

  1. Eingabetext：Geben Sie den zu übersetzenden Text im linken Textfeld ein oder fügen Sie ihn ein.
  2. Sprache auswählen：Wählen Sie die Ausgangs‑ und Zielsprache im Dropdown‑Menü oder nutzen Sie die automatische Erkennung.
  3. Übersetzungsmodus auswählen：
    • Standardübersetzung：Standardübersetzungsmodus, geeignet für die meisten Anwendungsfälle.
    • Intelligente Übersetzung：Unter Berücksichtigung von Kontext und Semantik wird eine genauere Übersetzung bereitgestellt.
    • Synonymauswahl：Bietet mehrere Synonymoptionen, damit Sie die passendste Übersetzung auswählen können.
    • Dokumentenübersetzung：Dokument hochladen für die Batch‑Übersetzung。
  4. Übersetzungsergebnis abrufen：Klicken Sie auf die Übersetzen‑Schaltfläche oder drücken Sie die Eingabetaste, das Ergebnis erscheint im rechten Textfeld.
  5. Barrierefreiheit nutzen：Sie können das Übersetzungsergebnis kopieren, vorlesen oder speichern.

Häufige Fragen

Wie wechsle ich das Thema?

Klicken Sie auf das Mond‑Symbol oben rechts, um zwischen hellem und dunklem Design zu wechseln.

Wie sehe ich den Verlauf ein?

Klicken Sie unten auf die Schaltfläche "Verlauf", um die vorherige Übersetzungshistorie einzusehen.

Wie speichere ich das Übersetzungsergebnis?

Klicken Sie im Übersetzungsergebnisbereich auf das Stern‑Symbol, um das Ergebnis zu Ihren Favoriten hinzuzufügen.

Wie konfiguriere ich die API?

Klicken Sie oben rechts auf das Einstellungssymbol und konfigurieren Sie Ihren Übersetzungs‑API‑Dienst im Reiter "API".
