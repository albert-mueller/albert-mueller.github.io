PyQuick Projektvorstellung

Ein OCLP-Zweig, basierend auf Python, bietet interessantere Funktionen

Kernfunktionen

1. Integration aller OCLP-Funktionen, einschließlich:

  • Aktuelle macOS Big Sur – macOS Tahoe-Images (*.app)
  • Unterstützung von macOS 11–15 Patches (macOS Tahoe vorerst nicht unterstützt)
  • Erlaubt alten Macs die Installation von OpenCore

2. Neue Funktionen

    Ermöglicht die manuelle Installation von KDK und Metal Libraries
  • Ermöglicht die Installation von VoodooHDA, macOS26 USB neuesten Erweiterungen usw.
