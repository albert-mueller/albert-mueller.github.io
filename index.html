OpenCore Legacy Patcher – Instructions for T2 Macs

What you need to do once you reach the Reboot to apply screen on a T2 Mac.

This guide applies to the following Macs only:

  • iMac 2020 (Intel)
  • iMac Pro 2017
  • Mac mini 2018
  • MacBook Air 2018
  • MacBook Air 2019
  • MacBook Air 2020
  • MacBook Pro 2018
  • MacBook Pro 2019
  • MacBook Pro 2020 (two Thunderbolt 3 ports)

To be able to boot OpenCore, you need to disable Secure Boot and System Integrity Protection (SIP) on T2 Macs. Why? T2 Macs don't trust OpenCore, so Secure Boot blocks it. Disabling SIP is also absolutely required to boot the installation media. If T2 Macs trusted any boot manager, they would also trust a malicious one, which would be a serious security risk.

These instructions are for T2 Macs only. They do not apply to non-T2 Macs.

Part 1 – Disable Find My

  1. Once you reach Reboot to apply, don't restart yet. Before restarting your T2 Mac into OpenCore, you need to disable Find My first – otherwise it triggers Activation Lock and CPU throttling.
  2. Open System Settings (Systemeinstellungen).
  3. Go to Apple Account.
  4. Go to iCloud.
  5. Go to Show All (Alle anzeigen).
  6. Click on Find My Mac (Meinen Mac suchen).
  7. Disable Find My.
  8. Go back to the restart prompt in OpenCore Legacy Patcher.
  9. Click on Reboot.
  10. Click on Restart (Neu starten).

Part 2 – Disable Secure Boot in macOS Recovery

  1. Once the screen turns black, get ready to hold ⌘ Command + R.
  2. As soon as you hear the chime, immediately hold ⌘ Command + R until you see a progress bar.
  3. You have now booted into the macOS Recovery of your native macOS. Open the Utilities (Dienstprogramme) menu.
  4. Choose Startup Security Utility (Startsicherheitsprogramm).
  5. At Authentication required (Authentifizierung erforderlich), click Enter macOS password (macOS-Passwort eingeben).
  6. Set Secure Boot to No Security (Ohne Sicherheit) and Allowed Boot Media (Erlaubte Boot-Medien) to Allow booting from external or removable media (Starten von externen oder Wechselmedien erlauben).
  7. Close this window.

Part 3 – Disable SIP

  1. Go to Utilities (Dienstprogramme) › Terminal.
  2. Type the following and press Enter: 
    csrutil disable && csrutil authenticated-root disable

Part 4 – Boot OpenCore and the installer

  1. Click the Apple logo › Restart.
  2. Hold the ⌥ Option key.
  3. Choose EFI Boot.
  4. Press Space.
  5. Using the arrow keys, select Reset NVRAM and press Enter.
  6. The system will now restart.
  7. Select Install macOS with the arrow keys and press Enter.

Kernel panic or stall?

If you see a kernel panic or a stall at the Apple logo, please report the kernel panic or stall here: github.com/albert-mueller/OpenCore-Legacy-Patcher-T2/issues – or in the affected repository if you are using a fork instead. If you have already erased your drive, I recommend downgrading after reporting the kernel panic.
